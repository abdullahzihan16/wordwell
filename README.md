# Wordwell Dictionary

A static English-to-Bangla GRE dictionary built from `gre333.csv`.

## Open the dictionary

Double-click `index.html` to open it directly in your browser. No server, installation, or internet connection is required.

The page includes searchable words, definitions, example sentences, synonyms, Bengali meanings, context, and connected words. The entries are bundled in `dictionary-data.js` so browsers can use them when opening the page as a local file. If you edit `gre333.csv`, `dictionary-data.js` must also be regenerated to include those changes.
